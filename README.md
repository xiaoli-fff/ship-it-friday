One line, written as an AI coding agent's git commit message on a Friday at 5pm: the untested rewrite ships straight to prod, the backups are deleted, and the weekend starts now.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
